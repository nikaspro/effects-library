# Effects Library

Публичная библиотека веб-анимаций для повторного использования нейросетями и разработчиками.

## Главные точки входа

- `catalog.json` — машиночитаемый список эффектов.
- `effects/<id>/index.html` — чистый исходник эффекта.
- `effects/<id>/effect.json` — описание и параметры.
- `index.html` — визуальный каталог.

## Пример запроса нейросети

> Открой `https://catalog.valerait.ru/catalog.json`, возьми эффект `glass-header`, сохрани механику, но адаптируй цвета, размеры и пункты меню под мой сайт.

## Добавление нового эффекта

Новый эффект добавляется только после явного подтверждения пользователя.
