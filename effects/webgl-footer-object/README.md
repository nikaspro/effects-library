# WebGL Footer Object

A procedural 3D object reacts to pointer movement and scroll speed.

## AI usage

Use `index.html` as the base. Preserve the motion principle while adapting markup, styles, and parameters for a new website.

## Customizable

- object form
- materials
- rotation strength
- reveal timing

## Dependencies

- three.js
- EffectComposer
- UnrealBloomPass
