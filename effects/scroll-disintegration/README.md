# Scroll Disintegration

Изображение распадается на пиксельные слои при прокрутке и собирается обратно.

## Использование нейросетью

Возьми исходник `index.html` как основу. Сохрани принцип анимации, но адаптируй разметку, стили и параметры под новый сайт.

## Что можно менять

- исходное изображение
- число слоёв
- направление распада
- дистанция

## Зависимости

- Нет внешних зависимостей
