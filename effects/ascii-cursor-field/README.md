# ASCII Cursor Field

Символы собираются в текст, реагируют на курсор и плавно меняют композицию.

## Использование нейросетью

Возьми исходник `index.html` как основу. Сохрани принцип анимации, но адаптируй разметку, стили и параметры под новый сайт.

## Что можно менять

- CONFIG.lines
- сила реакции курсора
- скорость смены композиций

## Зависимости

- Нет внешних зависимостей
